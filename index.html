Dùng thế nào?

  1. Bấm nút tải ở trên → lưu file Phosani3D-Windows.zip.
  2. Chuột phải vào file zip → chọn Extract All.
  3. Mở thư mục vừa giải nén → bấm đúp Phosani3D.exe (không cần cài đặt).

Lần đầu mở, Windows có thể hiện cảnh báo “Windows protected your PC”. Bấm More info → Run anyway.

Trong app có gì?

  • Soạn slide, hiệu ứng, chuyển cảnh và trình chiếu như PowerPoint
  • Thêm mô hình 3D rồi tự làm hoạt ảnh bằng các khóa
  • Lắp xương cho nhân vật
  • Nhóm đối tượng, khóa/ẩn lớp, ẩn slide
  • Gắn liên kết, chân trang, tìm & thay thế
  • Xuất ra PowerPoint (.pptx)
